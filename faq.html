FAQ

Questionsfréquentes.

C'est vraiment gratuit ?

Oui. Licence MIT : pas d'abonnement, pas de compte, pas de version payante. Le code est sur GitHub.

Je peux récupérer ma collection rekordbox ?

Oui, par l'export XML : morceaux, infos, hot cues, memory cues, boucles, grilles, playlists et dossiers. Réimport possible sans doublons.

Mes fichiers audio sont-ils modifiés ?

Non. Tags, cues et analyses sont enregistrés dans ta bibliothèque Reboxed, pas dans tes fichiers.

Quel matériel est pris en charge ?

DDJ-GRV6, DDJ-FLX2, FLX4, FLX6 et FLX10 avec un plugin fourni. Les autres contrôleurs Pioneer si leur mapping est dans une installation rekordbox, ou avec un plugin créé depuis leur .midi.csv. Sur CDJ / XDJ, avec une clé exportée par Reboxed.

Faut-il une carte graphique pour les stems ?

Non, tout tourne sur le processeur. FAST va environ 7 fois plus vite que le temps réel.

Comment mettre à jour ?

Depuis la 1.11.0, Reboxed te prévient quand une version sort : clique sur « ⬆ Update » en haut, il se met à jour et redémarre. Ta bibliothèque est gardée.

J'ai un clavier AZERTY.

Il est détecté tout seul. Tous les raccourcis se changent dans Préférences ▸ Keyboard.

Et sur Mac ?

Pas pour l'instant : Windows uniquement.

Je peux contribuer ?

Oui : signale un bug ou propose une amélioration sur GitHub, ou crée le plugin de ton contrôleur.

Prêt ?

Reboxed , gratuit.
