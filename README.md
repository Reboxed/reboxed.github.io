# Reboxed — site web

Site de [Reboxed](https://github.com/Vlocky1/Reboxed), publié avec GitHub Pages : https://vlocky1.github.io/

- Les captures (`assets/shots`) sont faites avec `npm run shots` dans le dépôt Reboxed.
- La démo audio (`assets/stems`) est « Hot Core » d'Alex Beroza ft. Snowflake, sous licence CC BY 3.0 (ccMixter). Elle a été séparée en stems par Reboxed.
- La version et le lien de téléchargement se changent dans `assets/site.js` (`VERSION`).
